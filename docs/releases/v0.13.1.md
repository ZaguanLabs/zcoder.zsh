# v0.13.1 — UTF-8 transcript hotfix

Binary tool output can no longer prevent strict UTF-8 clients from loading a
remote session. This fixes a protocol-1 failure where a command printed gzip
data into a transcript: the server returned HTTP 200 with a complete JSON body,
but invalid UTF-8 bytes caused clients to reject the response.

## What changed

- JSON encoding replaces malformed UTF-8 sequences with `�` (U+FFFD), preserving
  valid Unicode and normal JSON escaping.
- HTTP responses also repair previously serialized cached events and calculate
  `Content-Length` after repair.
- Existing affected transcripts become readable after upgrading and restarting
  the server. Original stored transcript bytes are preserved; no migration or
  manual session repair is required.

The fix uses native Zsh byte handling, works independently of the process
locale, and adds no runtime dependencies. Protocol 1 and Zsh 5.8 compatibility
remain unchanged.

## Verification

The application suite passes 2,247 checks on Zsh 5.9.2. Compilation and all 54
focused UTF-8 regressions pass on Zsh 5.8. Tests cover binary command capture,
saved and live events, cached HTTP responses, byte counts, malformed and
truncated encodings, valid Unicode, and large strings. An independent strict
UTF-8/JSON decoder also verified the actual affected NAS event.

## Source downloads and upgrade

The attached `zcoder.zsh-0.13.1.tar.gz` and `zcoder.zsh-0.13.1.zip` include the
pinned zcurses sources at `bc231768168992d71c2e87c7ef55c984cfc5ffb9`.
`SHA256SUMS` covers both archives. These are source-only packages, without
prebuilt native modules or Zsh wordcode. GitHub's automatic source archives
omit submodule contents; use the attached archives for complete sources.

For a Git checkout, stop the agent, pull the release, run
`git submodule update --init --recursive`, then `make compile` and restart.
For an attached source archive, extract it, run `make compile`, and restart.
The optional curses module's build requirements are described in the
[development guide](https://github.com/ZaguanLabs/zcoder.zsh/blob/v0.13.1/docs/development.md#building-the-curses-dependency).
