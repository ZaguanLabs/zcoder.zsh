# zcoder.zsh v0.11.2

v0.11.2 refreshes the default model used by the Antigravity consultant and
worker commands.

## Changed

- `/agy` and `/agy!` now default to `gemini-3.8-flash-high`.
- `ZCODER_AGY_MODEL` remains available for explicit model overrides.
- The interface reference reflects the new default, and the 1,002-test suite
  now verifies the model passed to the Antigravity CLI.

Review the [v0.11.1...v0.11.2 change set](https://github.com/ZaguanLabs/zcoder.zsh/compare/v0.11.1...v0.11.2).
