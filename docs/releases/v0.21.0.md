# v0.21.0 — Keep your place

Read a document, find an earlier conversation, and return to your draft without
losing your place. zcoder.zsh 0.21.0 brings workspace Markdown tabs, cleaner
session lists, and a fix for the sidebar focus jump. It also aligns model warm-up
with real requests so more of the prompt can be reused by Ollama.

This release collects the changes since v0.20.0.

## Browse conversations at your own pace

Press **Alt+1**, then use **Up/Down** to browse saved conversations. Loading a
session or preparing its model now keeps focus in Sessions, so you can continue
through the list. Press **Alt+2** when you want to return to the prompt; your
draft and caret position are preserved. An explicit focus change during loading
is respected. The fix applies to local and remote session selection.

Empty drafts no longer create saved conversations or clutter the sidebar. Saved
session lists now use an atomically updated index, with validation and recovery
when it is missing or stale. Committed session data remains authoritative, and
legacy histories continue to work. The terminal title also identifies the
current session and project.

## Keep reference documents beside the conversation

Use `/open README.md` to open a read-only Markdown tab. Up to four documents can
stay open, each retaining its scroll position. **Alt+3** selects Coding;
**Alt+4–Alt+7** select document tabs; **Alt+2** returns to your prompt draft.

The reader supports local workspaces and compatible remote servers, with native
Markdown rendering and a Zsh fallback. Open-document paths accompany submitted
requests as context; opening a document does not automatically send its contents
to the model. File access stays within the workspace.

## Warm up the prompt you will actually use

Warm-up now shares the normal request builder, keeping the model, instructions,
tool ordering, thinking mode, and context settings aligned. It no longer forces
thinking off or overrides temperature. The changing timestamp remains at the
end of the system prompt.

The disposable readiness message and small generation limit remain separate
from real conversation history. Warm-up responses never execute tools or enter
the saved session. This improves the conditions for prompt-prefix reuse;
actual latency savings depend on the model, template, and Ollama cache state.

## Upgrade

Stop the running agent, update the checkout, then restart your usual launcher:

```sh
git pull --ff-only
git submodule sync --recursive
git submodule update --init --recursive
make compile
```

Existing launcher models, profiles, workspaces, and token files can be retained.
The project continues to target **Zsh 5.8 or newer**. The README now correctly
identifies the project's **Apache 2.0** license.
