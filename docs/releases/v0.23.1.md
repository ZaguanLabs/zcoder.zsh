# v0.23.1 — zdraw dependency update

This patch release records the updated zdraw dependency and corrects the
application version to v0.23.1.

- Pin zdraw to `3ab773ca8ecd24c541ca9fc2fdbe739abff5a3f8` (v0.1.4).
- Include the Bit Lantern Pro navigation documentation added since v0.23.0.

For an existing checkout, stop the headless services, pull the update, run
`git submodule sync --recursive` and `git submodule update --init --recursive`,
then run `make compile` before restarting the launchers through the service
manager. Preserve each launcher's model, profile, workspace, and token file.
