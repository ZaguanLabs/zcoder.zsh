# zcoder.zsh v0.11.1

v0.11.1 fixes malformed Ollama requests immediately after a successful
conversation compaction.

## Fixed

- Recent conversation records retained alongside a checkpoint now preserve
  their Zsh array boundaries. Previously, a retained suffix containing more
  than one record was joined into one scalar, producing adjacent JSON objects
  without commas in the next Ollama request.
- The regression suite now compacts a history that retains multiple recent
  records and parses the complete rebuilt request as JSON. The native Zsh suite
  now contains 1,001 tests.
- Valid checkpoints, original history on failed compaction, workspace policy,
  and model-neutral structured checkpoint generation are unchanged.

## Upgrade note

The fix prevents newly compacted sessions from producing malformed follow-up
requests. A session already compacted by an affected version may contain a
collapsed persisted record and is not rewritten automatically; repair that
session explicitly or begin a new one after upgrading.

Review the [v0.11.0...v0.11.1 change set](https://github.com/ZaguanLabs/zcoder.zsh/compare/v0.11.0...v0.11.1).
